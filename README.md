# ezWondrousTails2

A Dalamud plugin that shows the probability of completing a row in the Wondrous Tails journal, plus the average odds if you shuffle.

This is an updated fork of [ezWondrousTails](https://github.com/MidoriKami/EzWondrousTails) by daemitus and MidoriKami. The original was archived and no longer works on the current version of Dalamud, so this fork brings it back up to date. All credit for the plugin goes to the original authors.

## Installation

1. In game, type `/xlsettings` and open the **Experimental** tab.
2. Under **Custom Plugin Repositories**, paste this link, click **+**, then **Save and Close**:

   https://raw.githubusercontent.com/FinaXIV/WondrousTailsSolver2/main/pluginmaster.json

3. Type `/xlplugins`, search for **ezWondrousTails2** and install it.

If you have the original ezWondrousTails installed, remove it first.
